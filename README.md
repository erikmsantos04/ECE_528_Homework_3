1. The MSP432 uses the eUSCI_A_modules for UART communication. Describe the function of the following registers:
* UCAxBRW (Baud Rate Control Word) - Holds 16-bit integer Baud-Rate divisor (UCBRx)
* UCAxMCTLW (Modulation Control Word) - Controls fractional part of baud rate generation
* UCAxCTLW0 (Control Word 0)  - Configures core UART operational parameters, such as clock source, character length, stop bits, parity, LS/MSB first, UART mode, and reset control
* UCAxRXBUF (Receive Buffer)  - Stores most recently received character from UART receive shift register
* UCAxTXBUF (Transmit Buffer) - Holds the data written by the CPU to be loaded into UART transmit shift register

  The purpose of this status register in the UART module is to provide real-time tracking of its status and concurrent error detection for serial communication. Bit 0 indicates whether the UART module is currently transmitting. Bit 6 handles framing errors. Bit 5 indicates overrun errors. Bit 4 indicates a parity error. 4. a) Write a function named UART2_Init that configures the eUSCI_A2 module for the following settings:
* Baud Rate: 115200
* Data Length: 8 bits
* Parity: None
* Stop Bits: 1
* Bit Order Most Significant Bit (MSB) First
* Clock Source: SMCLK (12 MHz)
* Pins: P3.2 (UCA2TXD) and P3.3 (UCA2RXD)

void UART2_Init(void)
{

	P3->SEL0 |= 0x0C;
	P3->SEL1 &= ~0x0C;
	
	EUSCI_A2->CTLW0 = 0x0001;

	EUSCI_A2->CTLW0 = 0x2081;
	
	EUSCI_A2->BRW = 0x0006;

	EUSCI_A2->MCTLW = 0x2081;

	EUSCI_A2->CTLW0 = 0x2080;
}

5. What is the function of the eUSCI_B module? How does SPI communication differ from UART communication n terms of:
* Synchornization
* Clocking
* Signaling
* Data Framing

The function of this module is to provide hardware support for synchronous serial communication like SPI and I2C.SPI is synchronous, has a shared clock, multi-wired bus, and continuous data framing (no start or stop bits).

6. a) Explain the role of the following SPI signals:
* SCLK  - Generated by the master device and is used to provide a stable timing reference for synchronous shifting and sampling of data
* CS - used to enable specific slave device (usually active low), also known as slave select
* MISO - Master In Slave Out. Carries serial data transmitted from the slaved device back to the master device
* MOSI - Master Out Slave In. Carries serial data transferred from the master device to the slave device

  b) What happens if multiple SPI peripheral devices have their CS line asserted simultaneously on the MSP432?

  It causes contention between the hardware on their shared bus, like a tug of war. This could lead to a short circuit in the bus, data corruption, and can damage the SPI pins.

7. a) Briefly describe the function of the UCBxCTLW0 (Control Word 0) register from the eUSCI_B module.

The function of this register is to handle the operation of I2C or SPI communication.

   b) Which bits need to be cleared or set in the UCBxCTLW0 register to configure the SPI mode used by the eUSCI_B module? Provide a description of each bit.

UCSWRST (Bit 0 SET) - software reset
UCSYNC (Bit 11 SET) - synchronous mode
UCMSB (Bit 13) - MSB/LSB select
UC7BIT (Bit 12) - 8/7 bit data length
UCPH (Bit 15) - Clock phase select (data transition and capture edge)
UCPOL (Bit 14) - Clock parity select
UCMST (Bit 3) - Master/Slave mode
UCMODEx (Bits 2-1) - defines behavior of UCxSTE pin
UCSSELx (Bits 7-6) - selects the clock source
UCSWRST (Bit 0 CLEAR) - reset to initialize with new configuration

   c) Which field in the UCBxCTLW0 register selects the clock source used by the eUSCI_B module? Provide the values used and the corresponding clock sources.

UCSSELx selects the clock source used by the eUSCI_B module. “00” chooses UCLK (external clock). “01” chooses ACLK (auxiliary clock). “10” chooses SMCLK. “11” chooses SMCLK.

8. a) Write a function named EUSCI_B0_SPI_Init that configures the eUSCI_B0 module for SPI communication with the following settings:
* SPI Mode: 0
* Data Length: 8 bits
* Bit Order: Most Significant Bit (MSB) First
* Clock Source: SMCLK (12 MHz)
* SPI Clock Frequency: 1 MHz
* SPI Format: 3-wire SPI
* SPI Pins:
  * P1.5: SCLK (UCB0CLK)
  * P1.6: MOSI (UCB0SIMO)
  * P1.7: MISO (UCB0SOMI)
  * P9.0: Active Low Chip Select (GPIO)
 
  void EUSCI_B0_SPI_Init(void)
  
{

	EUSCI_B0->CTLW0 |= 0x0001;

	EUSCI_B0->CTLW0 = 0xA981;

	EUSCI_B0->BRW = 0x000C;

	P1->SEL0 |= 0xE0;
	P1->SEL1 &= ~0xE0;

	P9->SEL0 &= ~0x01;
	P9->SEL1 &= ~0x01;
	P9->DIR |= 001;
	P9->OUT |= 0x01;

	EUSCI_B0->CTLW0 &= ~0x0001;
}
